# Работа над SQL-курсовой

Работайте только в `03SQL-CourseWork/`. Для лабораторных используйте инструкции
в `03SQL/`.

1. Определите затронутые таблицы или запросы. Прочитайте относящийся к ним
   раздел `docs/architecture.md` и порядок скриптов в `database/README.md`.
2. При изменении схемы обновите зависящие ограничения, индексы и запросы.
   При изменении поиска или ленты проверьте доступ к источнику до выдачи
   результата и сохраните происхождение цитат и графовых связей.
3. Сверьте описание модели со скриптами. Если решение изменилось, обновите
   архитектурную документацию. Сообщите, какие файлы изменены и как проверены;
   отдельно укажите, выполнялись ли скрипты на SQL Server 2025.
