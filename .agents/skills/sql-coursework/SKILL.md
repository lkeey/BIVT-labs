# Работа над SQL-курсовой

1. Прочитайте AGENTS.md, database/README.md и docs/architecture.md.
2. Основная модель реляционная; SQL Graph ограничен UserNode и Follows.
3. Меняйте SQL, Go, OpenAPI и документацию согласованно. Сохраняйте ACL и документы.
4. Не возвращайте RAG/векторы/модели. PostgreSQL должен сохранять предметные правила.
5. Проверяйте новую тестовую БД. Не сбрасывайте существующие данные.
6. Выполните проверки README и явно укажите, запускались ли реальные SQL и Firebase.
