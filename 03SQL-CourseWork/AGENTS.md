# Правила для курсовой по SQL Server

Этот каталог — отдельный проект курсовой на SQL Server 2025 и T-SQL. Не смешивай
его скрипты и настройки с лабораторными из `03SQL/`, где используются SQL Server
2019 и PostgreSQL 16.

- Для состава проекта и принятой архитектуры смотри `README.md` и
  `docs/architecture.md`; открывай только те разделы, которые относятся к задаче.
- Схему, графовые таблицы, начальные данные и запросы храни в упорядоченных
  файлах `database/`. Поддерживай SQL Server-специфичный синтаксис и проверяй
  совместимость с SQL Server 2025.
- HTTP-контракт меняй в `api/openapi.yaml` вместе с затронутой SQL-операцией.
  `x-implementation-status: planned` означает, что серверный маршрут ещё не
  реализован; не выдавай контракт за работающий API.
- SQL Server отвечает за реляционные данные, SQL Graph, текстовые фрагменты и
  выборку с проверкой доступа. Не выбирай embedding-модель и размер вектора без
  решения в документации проекта. OCR, создание embeddings и генерация ответа
  LLM выполняются на внешнем прикладном уровне; не представляй их как встроенные
  возможности T-SQL.
- Сохраняй связь извлечённых сущностей и рёбер с исходным материалом и его
  координатами. Поиск и рекомендации должны сначала учитывать доступность
  источников пользователю.
- Для проверки изменяющих данные запросов используй транзакцию с `ROLLBACK`.
  Инициализационные скрипты, предназначенные для постоянного применения,
  оставляй повторяемыми и явно документируй их порядок.
- Для повторяемого процесса работы с моделью смотри repo-local Skill
  `../.agents/skills/sql-coursework/SKILL.md`.
