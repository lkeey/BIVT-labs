# T-SQL курсовой

Скрипты рассчитаны на **SQL Server 2025** с установленным компонентом Full-Text Search.
Работайте в отдельной базе `SocialNetworkDB`. Файлы применяются по номеру в имени;
`GO` распознаётся `sqlcmd` и SSMS. Повторный запуск сохраняет уже созданные таблицы
и индексы; изменения существующей схемы требуют отдельной миграции или новой пустой
учебной базы.

| Порядок | Файл | Результат |
| --- | --- | --- |
| 00 | [`00-create-schemas.sql`](00-create-schemas.sql) | Схемы `auth`, `social`, `knowledge`, `assistant`, `ops`. |
| 01 | [`01-social-nodes.sql`](01-social-nodes.sql) | Учётные записи, профили, сообщества и материалы. |
| 02 | [`02-content.sql`](02-content.sql) | Ревизии текстов, бинарные документы, извлечённый текст и фрагменты. |
| 03 | [`03-knowledge-graph.sql`](03-knowledge-graph.sql) | Модель embeddings, векторы 384D и граф знаний с доказательствами. |
| 04 | [`04-social-content-edges.sql`](04-social-content-edges.sql) | Подписки, членство, авторство, размещение, комментарии и реакции. |

Скрипты 07–11 завершают прикладную часть модели; применяйте их после 00–06.
Пример запуска одного файла после создания базы:

```bash
sqlcmd -S localhost -d SocialNetworkDB -U sa -i database/00-create-schemas.sql -b
```

Параметр `-b` останавливает выполнение при ошибке. Затем запустите остальные
файлы по порядку.

## Состав модели

Одна база содержит **32 таблицы**: 5 узлов SQL Graph, 9 рёбер SQL Graph и 18
реляционных таблиц. Условия связей графа ограничивают типы узлов. Уникальные
индексы запрещают две текущие ревизии одного материала и дублирующиеся активные
связи. Бинарный оригинал PDF/DOCX хранится в `knowledge.DocumentVersion.FileBytes`
(`varbinary(max)`), введённый пользователем текст — в `PlainText`; из обоих
источников формируются ревизия текста и цитируемые фрагменты.

`knowledge.ChunkEmbedding.Embedding` использует `vector(384)`. Строка
`knowledge.EmbeddingModel` фиксирует `intfloat/multilingual-e5-small`; приложение
передаёт готовые векторы. Для учебного объёма поиск считает точное
`VECTOR_DISTANCE`, сочетает его с SQL Full-Text и графовыми связями.

Исторические ревизии остаются для аудита, но представления поиска используют
только опубликованное текущее содержание. Проверка доступа выполняется по
активной учётной записи, видимости сообщества и активному членству; закрытое
сообщество также доступно владельцу. Комментарий наследует доступ от исходного
поста. Извлечённые рёбра хранят фрагмент-основание, координаты, уверенность и
версию извлекателя; имена сущностей автоматически не объединяются.
