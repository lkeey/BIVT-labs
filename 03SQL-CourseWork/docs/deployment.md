# Запуск и Firebase

## SQL и API

1. Создайте новую пустую SQL Server 2025 базу и примените скрипты по
   [database/README.md](../database/README.md). Старую базу не сбрасывайте.
2. Создайте отдельный SQL login/user и включите его в `coursework_api`.
   Не используйте администратора для работающего HTTP API.
3. Скопируйте `.env.example` в локальный `.env`, задайте проверяемое TLS-соединение
   SQLSERVER_DSN, FIREBASE_WEB_API_KEY и точный CORS_ORIGIN.
4. Запустите `docker compose up --build api` либо Go по [backend/README.md](../backend/README.md).
5. Проверьте `/healthz`, `/readyz`, затем запрос с настоящим Firebase ID token.

## Firebase для преподавателя

Проект сайта уже указан в `web/.firebaserc`: `bivt-labs-sql-coursework`.
Публичная конфигурация приложения находится в `web/public/config.js`.
Она не является административным доступом к Firebase.

В [web/README.md](../web/README.md) описаны вход и демонстрация. Покажите
Authentication, Hosting и связь Firebase UID с `auth.UserAccount` в SQL.
Для этого не нужно добавлять Firestore или переносить реляционную БД в Firebase.

Cloud API должен иметь известный HTTPS URL. До проверки его готовности
`backendReady` остаётся false. Укажите API origin в `apiBaseUrl` и тот же origin
сайта в CORS_ORIGIN. Firebase Hosting не запускает Go API сам по себе.
Не меняйте флаг на true только ради скрытия предупреждения.

Публикация Hosting и настройка провайдеров входа требуют доступа владельца
к существующему Firebase-проекту. PR содержит конфигурацию, но сам по себе
не подтверждает облачный вход или новое развёртывание. Ключи сервисных аккаунтов
и SQL-пароли никогда не помещаются в `web/public` или Git.

## Приёмка

- Вход, выход и повторный вход Firebase; незалогиненный API получает 401.
- Создание сообщества/публикации/комментария/реакции.
- Второй пользователь не читает закрытые материалы и бинарные файлы.
- Подписка меняет ленту; удалённая публикация не видна.
- Загрузка, новая версия и скачивание документа сохраняют байты.
- Применение SQL на новой БД; прежняя база остаётся нетронутой.
