# SQL Server на VPS

Используйте [порядок T-SQL](../database/README.md).

Общая актуальная инструкция: [запуск и Firebase](deployment.md).

Новая схема не является миграцией старой базы. Сначала создайте отдельную
пустую учебную базу; старые данные и файлы сохраняйте до проверенной миграции.
Работающему API выдавайте минимальную роль, проверяйте TLS и точный CORS origin.

Автоматического создания облачных ресурсов, изменения тарифов и развёртывания
в этом PR нет. Доступность и стоимость инфраструктуры проверяются отдельно.
