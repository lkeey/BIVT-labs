# Обработчик индексации

`index_worker.py` обрабатывает `ops.IndexOutbox` вне SQL Server. Он извлекает
текст из постов, комментариев, DOCX и PDF, распознаёт русскоязычные страницы
сканированного PDF, делит текст на цитируемые фрагменты, строит 384-мерные
embeddings и передаёт результат одной атомарной процедуре
`ops.usp_CommitIndexResult`. Для удалённых или отозванных материалов вызывает
`ops.usp_CommitIndexDeletion`. Данные и SQL Graph записывает только SQL Server
после повторной проверки токена задания и состояния источника.
Перед запуском примените скрипты `database/00`–`database/17` в порядке из
[`database/README.md`](../database/README.md); роль `coursework_worker` задаёт
скрипт `17-auth-and-roles.sql`.

## Подготовка

Нужны Python 3.11+, Microsoft ODBC Driver 18 for SQL Server, Tesseract OCR с
языковым пакетом `rus` и доступ к SQL Server 2025. Для macOS можно установить
Tesseract через `brew install tesseract tesseract-lang`; для Linux используйте
пакеты `tesseract-ocr` и `tesseract-ocr-rus`. Установка ODBC Driver 18 зависит
от ОС и описана [Microsoft](https://learn.microsoft.com/en-us/sql/connect/odbc/download-odbc-driver-for-sql-server?view=sql-server-ver17).

Из каталога `worker/`:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Модель `intfloat/multilingual-e5-small` загружается при первом запуске из
Hugging Face в системный кеш на фиксированной ревизии
[`fd1525a9fd15316a2d503bf26ab031a61d056e98`](https://huggingface.co/intfloat/multilingual-e5-small/tree/fd1525a9fd15316a2d503bf26ab031a61d056e98).
Worker сверяет этот SHA с `knowledge.EmbeddingModel.ModelVersion`; его код не
выполняется как remote custom code.
Заранее прогрейте модель на машине с доступом к сети, если сервер индексации
будет работать без сети. Кеш (`HF_HOME`) и виртуальную среду храните вне Git.

Задайте `COURSEWORK_SQL_ODBC_CONNECTION_STRING` в окружении процесса. Строка
должна включать `Driver={ODBC Driver 18 for SQL Server}`, `Server`,
`Database=SocialNetworkDB`, отдельную учётную запись обработчика и
`Encrypt=yes`. Для рабочего сертификата включайте проверку сертификата;
`TrustServerCertificate=yes` подходит только локальному учебному серверу.
Пароль не помещайте в репозиторий или аргументы команды. SQL-роль обработчика
должна иметь только `EXECUTE` на процедуры очереди и записи индекса.

```bash
.venv/bin/python index_worker.py
.venv/bin/python index_worker.py --loop --poll-seconds 10
```

Первый вызов обрабатывает максимум одно задание и завершает работу. Второй
непрерывно опрашивает очередь. Модель прогревается **до** получения задания.
Во время OCR и создания векторов отдельное соединение продлевает 10-минутную
аренду; перед записью результата обработчик проверяет, что продление удалось.
Просроченные задания возвращаются в очередь процедурой
`ops.usp_RequeueExpiredIndexOutbox`; после трёх неудачных попыток событие
остаётся `FAILED` до явного `ops.usp_RetryIndexOutbox`.

## Приватный сервис вектора вопроса

`embed_service.py` использует ту же функцию загрузки закреплённой модели, что
и индексатор. Модель и запрос `query: проверка модели` прогреваются один раз
перед запуском HTTP; на каждый запрос создаётся только вектор вопроса.
Сервис не соединяется с SQL Server, поэтому для отдельного процесса достаточно
облегчённых зависимостей:

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-embed.txt
.venv/bin/python embed_service.py
```

По умолчанию сервис слушает только `127.0.0.1:8765`. Его внутренний контракт:

```http
POST /embed HTTP/1.1
Content-Type: application/json

{"question":"Какие документы посвящены базам данных?"}
```

Ответ: `{"embedding":[...],"model":"intfloat/multilingual-e5-small",
"revision":"fd1525a9fd15316a2d503bf26ab031a61d056e98"}`; массив содержит
ровно 384 нормализованных конечных числа. `GET /healthz` сообщает о готовности.
Сервис принимает тело до 8192 байт и вопрос от 1 до 2000 символов. На чтение
HTTP-запроса даётся 10 секунд, на выдачу вектора — 30 секунд. Одновременно
выполняется один расчёт; пока он занят, сервис возвращает `503`. После
таймаута вычисления возвращается `504`, новое не запускается до завершения
старого. `SIGTERM` и `SIGINT` корректно останавливают HTTP-сервер.

Для запуска за границей localhost задайте случайный секрет минимум 32 символа
через `COURSEWORK_EMBED_BEARER_TOKEN` и укажите `--host` с IPv4-адресом.
Тогда `POST /embed` требует `Authorization: Bearer <secret>`. Такой процесс
размещайте только в приватной сети за TLS-прокси; прямой публичный HTTP
передавал бы секрет открытым текстом. Сервис не отдаёт CORS-заголовков и не
пишет вопрос или заголовок авторизации в журнал. Секрет храните вне Git.

Для Go backend задайте `EMBEDDING_SERVICE_URL` равным
`http://127.0.0.1:8765/embed`, если оба процесса на одной машине; для разных
машин используйте приватный HTTPS URL. При включённом Bearer задайте backend
`EMBEDDING_SERVICE_TOKEN` с тем же секретом. Backend проверяет имя модели,
SHA ревизии и размерность ответа перед передачей JSON-вектора в
`assistant.usp_SearchRag`.

## Содержимое индекса

- PDF: текст извлекается постранично; если страница содержит менее 30 символов,
  для неё запускается русский OCR. Номер страницы записывается в `Chunk.PageNo`.
  PDF с паролем отвергается.
- DOCX: текст абзацев и таблиц берётся из `word/document.xml`. Заголовки,
  колонтитулы, изображения и текст внутри них пока не извлекаются.
- Текстовые публикации и документы: индексируются непосредственно; номер
  страницы отсутствует.
- Все фрагменты сохраняют точные смещения в извлечённом тексте. Единицу
  смещения обработчик определяет по `LEN` текущей SQL collation, чтобы
  корректно обработать символы вне BMP. Поля свидетельств графа ссылаются на
  реальные подстроки фрагмента.
- Для каждого фрагмента используется префикс `passage:` модели
  `intfloat/multilingual-e5-small`; вектор нормализуется и проверяется на
  384 конечных числовых значения.
- Извлечение сущностей и отношений пока **ограничено явными русскими
  конструкциями**: «Иван Петров работает в компании …», «… участвует в
  мероприятии …», «Конференция … проходит в Москве», вариант с `городе`, и
  `Тема: …`. Названия организаций и событий могут быть в кавычках `«…»`. Это
  прозрачные правила `rules-ru-v1`, а не полноценная NER-модель. Неопознанный
  текст остаётся доступен для полнотекстового и векторного поиска; пустой граф
  для такого текста ожидаем.

Ограничения входа: файл до 10 МиБ, PDF до 300 страниц, извлечённый текст до
2 млн символов. Ошибки не создают частично готовые фрагменты: запись результата
выполняется одной транзакцией SQL. После изменения материала старая ревизия
сразу исключается из доступных поисковых представлений, даже до очистки
производных данных очередью.
