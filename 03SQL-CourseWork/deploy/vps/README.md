# VPS

Сервис `coursework-api.service` запускает только Go API. Файл `api.env.example`
содержит имена настроек без секретов. SQL Server и HTTPS reverse proxy настраиваются
отдельно; см. [запуск](../../docs/deployment.md).

Сервисы модели и индексирования удалены. Если они ранее были установлены на VPS,
владелец должен отдельно остановить их после проверки новой версии; PR не меняет VPS.
Не удаляйте старые базы/файлы. Caddyfile.example остаётся примером, не живой конфигурацией.
