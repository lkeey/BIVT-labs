# Лабораторная работа №3. Порождающие паттерны

**Автор:** Кирюшин Алексей Александрович · **Группа:** БИВТ-25-4-6 · **2026**

## Цель и задание

Реализовать Singleton, Factory Method, Abstract Factory и Builder на примере
подготовки пошаговой стратегии.

## Решение

- `GameConfig` — объект Kotlin, который предоставляет единственный набор
  настроек карты и начального количества золота.
- `UnitFactory` с `ArcherFactory` и `SwordsmanFactory` инкапсулирует создание
  конкретного юнита (Factory Method).
- `FactionFactory` с фабриками королевства и орков создаёт согласованные
  объекты фракции: юнита и здание (Abstract Factory).
- `ScenarioBuilder` пошагово собирает сценарий и проверяет, что в нём есть
  хотя бы один юнит (Builder).

## Запуск

Из `03TechnologiesOfProgramming`:

```bash
./gradlew :lab03:run
```

Исходный код и демонстрация находятся в `src/main/kotlin/lab03/Main.kt`.

## Вывод

Порождающие паттерны отделяют выбор создаваемого объекта от кода сценария.
Новые типы юнитов и фракций можно добавлять расширением фабрик, а не
переписывая сборку начальной ситуации.
