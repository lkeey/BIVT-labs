# Лабораторная работа № 1. Git и монорепозиторий

## Цель

Освоить базовый цикл работы с Git и GitHub на примере уже существующего личного
монорепозитория `BIVT-labs`, в котором учебные материалы по разным предметам
хранятся в отдельных каталогах.

## Структура

Каталог `03TechnologiesOfProgramming/` добавлен как отдельный предмет. Внутри
него размещены семь лабораторных работ, а исходный код, инструкции и отчёты
сгруппированы по лабораторным. Другие предметы в корне репозитория сохраняются
рядом и не смешиваются с этими материалами.

## Рабочий процесс

```bash
git status --short
git switch -c codex/7-technologies-programming-labs
git add 03TechnologiesOfProgramming
git diff --cached --check
git commit -m "Add Kotlin technologies of programming labs"
git push -u origin codex/7-technologies-programming-labs
```

После отправки ветки изменения проходят проверку в pull request, затем
объединяются с `main`. При добавлении материалов важно указывать путь только
к каталогу нужного предмета: это позволяет вести несколько дисциплин в одном
репозитории и проверять их независимо.

## Результат

Подготовлен каталог нового предмета в существующем монорепозитории. Все семь
лабораторных имеют отдельные подкаталоги; работы на Kotlin собираются одним
Gradle-проектом.

## Вывод

Размещение учебных работ по предметам в отдельных каталогах делает единый
репозиторий удобным для сопровождения. Ветвление, проверка diff и pull request
дают контролируемый процесс публикации изменений.
