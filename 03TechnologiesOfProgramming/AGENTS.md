# Правила для проекта «Технологии программирования»

- Работай только в `03TechnologiesOfProgramming/`, если задача явно не просит изменить другой проект.
- Проект использует Gradle Wrapper и независимые модули `lab01`–`lab07`. Сначала прочитай корневой [`README.md`](README.md) и README затронутого модуля.
- Используй JDK 17+ и `./gradlew` из корня проекта; не подменяй wrapper установленным глобально Gradle.
- Проверки запускай из `03TechnologiesOfProgramming/`: `./gradlew build`; для тестов лабораторной 6 — `./gradlew :lab06:test`. Команды запуска модулей и проверка документации лабораторной 1 перечислены в корневом README.
- Не меняй другие модули ради локальной задачи без необходимости и не добавляй каталоги сборки Gradle или IDE.
- Если меняется поведение лабораторной, обнови её README и проверь согласованность инструкции с реализацией.
