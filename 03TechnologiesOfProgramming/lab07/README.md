# Лабораторная работа №7. ORM и SQLite

**Автор:** Кирюшин Алексей Александрович · **Группа:** БИВТ-25-4-6 · **2026**

## Цель и задание

Создать сущности `Category` и `Product`, связать продукты с категориями и
реализовать основные CRUD-операции с помощью ORM.

## Решение

Используются Exposed `1.5.0`, Exposed JDBC и драйвер SQLite JDBC `3.50.2.0`.
Таблица `Categories` хранит названия категорий. В `Products` находятся имя,
цена и внешний ключ категории. `ProductRepository` создаёт записи, выводит
товары категории, переносит товар в другую категорию и удаляет категорию
вместе с её товарами.

Приложение создаёт демонстрационную базу `build/lab07-demo.db` и заполняет её
данными при запуске. Для выполнения задания внешняя установка сервера БД не
нужна.

## Запуск

Из `03TechnologiesOfProgramming`:

```bash
./gradlew :lab07:run
```

## Вывод

Exposed описывает таблицы и операции Kotlin-кодом, а SQLite хранит данные в
локальном файле. Репозиторий отделяет операции с базой от демонстрационного
сценария.
