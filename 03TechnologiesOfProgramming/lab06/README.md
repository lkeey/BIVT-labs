## Цель и задание

Реализовать класс банковского счёта и покрыть его модульными тестами с
мокированием внешней зависимости.

## Решение

`BankAccount` поддерживает пополнение, снятие и чтение баланса. Суммы должны
быть конечными и положительными; счёт не позволяет снять больше остатка и
возвращает сообщение `Insufficient funds`. После успешной операции счёт
сообщает транзакцию через `TransactionLogger`.

В тестах `MockTransactionLogger` записывает переданные события. Проверяется
начальный баланс, отказ для некорректных сумм, пополнение и снятие, отказ при
недостатке средств, неизменность баланса после ошибки и отсутствие ложного
вызова журнала.

## Запуск

Из `03TechnologiesOfProgramming`:

```bash
./gradlew :lab06:test
./gradlew :lab06:run
```

Тесты расположены в `src/test/kotlin/lab06/BankAccountTest.kt`.

## Вывод

Передача журнала через интерфейс делает класс счёта изолированным от способа
хранения событий. Mock-объект позволяет проверить как результат операции, так
и корректное взаимодействие с этой зависимостью.
