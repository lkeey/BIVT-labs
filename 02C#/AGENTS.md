# Правила для C#-проекта

- Работай только в `02C#/`, если задача явно не просит изменить другой проект.
- При изменении поведения или структуры обратись к README затронутой
  лабораторной; для лабораторных 8–11 при необходимости используй также
  [`Labs_08-11_Overview.md`](Labs_08-11_Overview.md).
- Лабораторные состоят из независимых приложений. Корневой `BIVT-labs.sln` включает только три проекта `lab01`; не считай его сборкой всех лабораторных.
- Для запуска используй команду и проект, указанные в README конкретной лабораторной. Для лабораторных 5–9 доступен [`RUN_LABS.sh`](RUN_LABS.sh): запускай его из `02C#/`.
- Сохраняй структуру каждой лабораторной и её фактический формат отчёта. Не переноси файлы между лабораторными и не меняй форматы отчётов без явной причины в задаче.
- Не добавляй `bin/`, `obj/`, пользовательские файлы IDE и другие результаты сборки.
