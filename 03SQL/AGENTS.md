# Правила для SQL-материалов

- Работай только в `03SQL/`, если задача явно не просит изменить другой проект.
- При изменении запросов, данных или команд проверь относящиеся к задаче
  разделы README конкретной лабораторной. Сохрани её текущую структуру и
  расширения файлов: здесь нет единого шаблона `README.md` + `solution.sql`
  для всех работ.
- Соблюдай границы СУБД и диалектов:
  - `lab01`, `lab02`, `lab03` и `lab05` используют SQL Server и Transact-SQL; лабораторные 1–3 работают с `AdventureWorksLT2019`.
  - `lab04` — отдельный семинар по PostgreSQL 16. Используй PostgreSQL-синтаксис и материалы `schema.sql`, `seed.sql`, `solution.pqsql`; не заменяй их T-SQL.
  - Курсовая на SQL Server 2025 ведётся отдельно в `03SQL-CourseWork/`; не смешивай её схему, скрипты и требования с лабораторной средой SQL Server 2019.
- Сохраняй принятые в лаборатории имена и расположение файлов: например, `solution.sql` в `lab01`/`lab02`, нумерованные скрипты в `lab03`, PostgreSQL-файлы в `lab04` и существующие скрипты в `lab05`.
- Сначала студент предлагает идею и запрос; проверенный вариант добавляется в материалы соответствующей лабораторной после обсуждения.
- Любой временный запрос, меняющий учебные данные, оборачивай в транзакцию и заверши откатом: для SQL Server — `BEGIN TRANSACTION ... ROLLBACK`, для PostgreSQL — `BEGIN ... ROLLBACK`. Не фиксируй тестовые изменения через `COMMIT`.
- Не выполняй полный сброс базы или Docker volume при обычной проверке. Инструкции и безопасные команды среды SQL Server находятся в [`README.md`](README.md) и [`docker/README.md`](docker/README.md); для PostgreSQL следуй [`lab04/README.md`](lab04/README.md).
