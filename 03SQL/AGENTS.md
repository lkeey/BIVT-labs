# Правила для лабораторных по SQL

Правило корневого `AGENTS.md` о создании отчётов Microsoft Word не применяется
к каталогу `03SQL`.

Для каждой лабораторной сохраняются:

- условие и краткая идея решения в `README.md`;
- проверенные запросы в `solution.sql`.

Готовое решение заранее не добавляется: сначала студент предлагает идею и SQL,
после проверки и обсуждения они переносятся в файлы лабораторной.

Изменяющие учебные данные запросы выполняются внутри
`BEGIN TRANSACTION ... ROLLBACK`, чтобы база после проверки оставалась в
исходном состоянии.
