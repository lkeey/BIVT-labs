# Лабораторная работа №2 — Запросы к таблицам SELECT

Цель работы — извлечение, сортировка и фильтрация данных базы
`AdventureWorksLT2019`. Проверенные запросы находятся в
[`solution.sql`](solution.sql).

## Задача 1. Получение данных для транспортных отчётов

### 1.1. Получить список городов

Получить из `SalesLT.Address` все уникальные сочетания города (`City`) и региона
(`StateProvince`).

**Идея решения:** выбрать оба столбца с `DISTINCT`, чтобы удалить только
повторяющиеся пары города и региона.

### 1.2. Получить самые тяжёлые товары

Получить наименования десяти процентов самых тяжёлых товаров без включения
дополнительных строк с одинаковым весом.

**Идея решения:** отсортировать товары по весу по убыванию и ограничить результат
конструкцией `TOP (10) PERCENT`. `WITH TIES` не используется.

### 1.3. Получить самые тяжёлые 100 товаров без первых десяти

Получить наименования 100 самых тяжёлых товаров, не включая первые десять.

**Идея решения:** после сортировки по убыванию веса пропустить 10 строк через
`OFFSET`, затем получить следующие 100 через `FETCH NEXT`.

## Задача 2. Получение данных о товаре

### 2.1. Получить информацию о товарах модели 1

Получить наименования, цвета и размеры товаров с `ProductModelID = 1`.

**Идея решения:** выбрать три требуемых столбца и отфильтровать строки точным
условием в `WHERE`.

### 2.2. Отфильтровать товары по цвету и размеру

Получить номера и названия товаров цветов `Black`, `Red` или `White` и размеров
`S` или `M`.

**Идея решения:** использовать два независимых списка `IN`, соединённых
оператором `AND`.

### 2.3. Отфильтровать товары по началу товарного номера

Получить товарный номер, наименование и цену товаров, номера которых начинаются
с `BK-`.

**Идея решения:** применить `LIKE 'BK-%'`, где `%` обозначает любое количество
последующих символов.

### 2.4. Получить определённые товары по товарному номеру

Получить товарный номер, наименование и цену товаров, номера которых начинаются
с `BK-`, затем содержат символ, отличный от `R`, и заканчиваются дефисом и двумя
цифрами.

**Идея решения:** использовать шаблон `LIKE` с отрицательным диапазоном
`[^R]`, `%` для средней части и двумя диапазонами `[0-9]` в конце.
