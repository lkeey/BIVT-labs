# Лабораторная работа №1 — Введение в Transact-SQL

Запросы выполняются в базе `AdventureWorksLT2019`. Проверенные решения будут
добавляться в [`solution.sql`](solution.sql) по одному после обсуждения.

## Задача 1. Извлечение данных по клиентам

### 1.1. Получить сведения о клиентах

Написать запрос, который извлекает все столбцы для всех клиентов из таблицы
`SalesLT.Customer`.

**Идея решения:** _будет добавлена после обсуждения варианта студента._

### 1.2. Получить данные по имени клиента

Получить для всех клиентов пять отдельных столбцов: обращение (`Title`), имя,
отчество (если есть), фамилию и суффикс (если есть).

**Идея решения:** _будет добавлена после обсуждения варианта студента._

### 1.3. Получить имена клиентов и номера телефонов

Создать список для обзвона из трёх столбцов:

- продавец (`Salesperson`);
- `CustomerName` — приветствие в формате наподобие `Mr Smith`;
- номер телефона клиента.

**Идея решения:** _будет добавлена после обсуждения варианта студента._

## Задача 2. Получение данных о клиентах и продажах

### 2.1. Получить список компаний-клиентов

Сформировать столбец `CustomerCompany` в формате
`<идентификатор клиента>: <название компании>`, например
`78: Preferred Bikes`.

**Идея решения:** _будет добавлена после обсуждения варианта студента._

### 2.2. Получить список изменений заказа клиента

- `OrderRevision` в формате `<номер заказа> (<редакция>)`, например
  `SO71774 (2)`;
- `OrderDate` в стандартном формате ANSI `yyyy.mm.dd`, например
  `2015.01.31`.

**Идея решения:** _будет добавлена после обсуждения варианта студента._

## Задача 3. Получить контактную информацию клиента

### 3.1. Получить имена контактов с отчествами, если они известны

Сформировать один столбец `CustomerName`: `<имя> <фамилия>`, если отчество
неизвестно, либо `<имя> <отчество> <фамилия>`, если оно хранится в базе.

**Идея решения:** _будет добавлена после обсуждения варианта студента._

### 3.2. Получить первичные контактные данные

Вернуть идентификатор клиента и столбец `PrimaryContact`. В нём должен быть
адрес электронной почты, если он известен, иначе — номер телефона.

Для проверки сначала временно выполнить изменение:

```sql
UPDATE SalesLT.Customer
SET EmailAddress = NULL
WHERE CustomerID % 7 = 1;
```

Изменение необходимо заключить в `BEGIN TRANSACTION ... ROLLBACK`, чтобы не
сохранять его в учебной базе.

**Идея решения:** _будет добавлена после обсуждения варианта студента._

### 3.3. Получить статус доставки

Вернуть идентификаторы заказов, даты заказов и столбец `ShippingStatus` со
значением `Shipped` для заказов с известной `ShipDate` и
`Awaiting Shipment` для заказов без даты отправки.

Для проверки сначала временно выполнить изменение:

```sql
UPDATE SalesLT.SalesOrderHeader
SET ShipDate = NULL
WHERE SalesOrderID > 71899;
```

Изменение необходимо заключить в `BEGIN TRANSACTION ... ROLLBACK`, чтобы не
сохранять его в учебной базе.

**Идея решения:** _будет добавлена после обсуждения варианта студента._
