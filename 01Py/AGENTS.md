# Правила для Python-проекта

- Работай только в `01Py/`, если задача явно не просит изменить другой проект.
- Сначала прочитай [`README.md`](README.md) и README затронутой лабораторной: они описывают структуру, данные и ожидаемое поведение.
- Код лабораторных находится в `src/`, тесты — в `tests/`, входные и ожидаемые данные — в `data/`. Не удаляй и не перезаписывай учебные данные, нужные лабораторным.
- Используй Python 3.11+ и зависимости из `requirements.txt`. Команды из каталога `01Py`:
  - `pip install -r requirements.txt`
  - `pytest`
  - `black --check .`
  - `ruff check .`
- Не добавляй в изменения `__pycache__`, `*.pyc`, `.coverage`, кэши и другие результаты запуска.
- При изменении поведения обновляй README соответствующей лабораторной и связанные тесты.
